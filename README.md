\# Ozon Position Monitor



Автоматический мониторинг позиции товара в поиске OZON.



\## Что делает

\- Заходит на ozon.ru

\- Ищет товар по запросу

\- Прокручивает выдачу

\- Находит позицию товара по артикулу (SKU)

\- Сохраняет результат в CSV-файл



\## Технологии

\- Python 3

\- SeleniumBase (автоматизация браузера)
